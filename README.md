# Nova Digital — Landing Page

Современный одностраничный лендинг для вымышленного диджитал-агентства **Nova Digital**.

Чистый HTML/CSS/JS в одном файле, без внешних библиотек — только нативный код.

## 🚀 Запуск

Просто откройте `index.html` в браузере или запустите локальный сервер:

```bash
# Python
python3 -m http.server 8000

# Node
npx serve .
```

## 🎨 Цветовая гамма

- Тёмно-синий: `#0f172a`
- Белый: `#ffffff`
- Акцент (бирюзовый): `#14b8a6`

## 📄 Реализованные секции

| Секция | Описание |
|--------|----------|
| **Шапка** | Фиксированная навигация с логотипом, меню-бургером для мобильных и CTA-кнопкой |
| **Hero** | Крупный заголовок с градиентным текстом, CTA-кнопки, абстрактный фон (анимированные градиентные орбы + сетка), статистика |
| **Преимущества** | 4 карточки с SVG-иконками и hover-эффектами |
| **Услуги** | 4 карточки услуг с нумерацией и hover-анимацией |
| **Процесс работы** | Нумерованный список из 4 шагов с вертикальной линией-таймлайном |
| **Портфолио** | Сетка из 6 проектов с эффектом наведения (overlay + zoom) |
| **Отзывы** | Карусель из 3 отзывов с кнопками, точками и автопрокруткой |
| **Форма заявки** | Валидация полей (имя, email, телефон, сообщение) с сообщениями об ошибках и экраном успеха |
| **Футер** | Контакты, навигация, соцсети (Telegram, VK, Behance) |

## ✨ Анимации

- Плавное появление секций при скролле через **IntersectionObserver**
- Hover-эффекты на кнопках и карточках
- Анимированный абстрактный фон в hero
- Плавная карусель отзывов

## 📱 Адаптивность

- **Десктоп** (1200px+): полная сетка
- **Планшет** (≤1024px): 2 колонки в сетках
- **Мобильные** (≤768px): бургер-меню, 1 колонка, адаптивные отступы

## 🛠 Технологии

- HTML5
- CSS3 (CSS-переменные, Flexbox, Grid, media queries)
- Vanilla JavaScript (IntersectionObserver, DOM-манипуляции)
- Google Fonts (Inter)
